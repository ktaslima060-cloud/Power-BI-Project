# Manufacturing Analysis Dashboard

## 📌 Project Overview
This repository contains an end-to-end **Power BI** analysis focused on manufacturing operational performance. The project transforms production data from [`Manufacturing_Analysis.xlsx`](https://github.com/ktaslima060-cloud/Power-BI-Project/blob/main/Manufacturing_Analysis.xlsx) into an interactive dashboard to monitor plant metrics, evaluate output efficiency, and identify potential bottlenecks across the manufacturing workflow.

---

## 🛠️ Tech Stack & Tools
* **Power BI Desktop:** Data modeling, report layout, and custom visualizations.
* **Power Query (ETL):** Data extraction, transformation, cleaning, and schema normalization.
* **DAX (Data Analysis Expressions):** Custom measures, KPIs, aggregations, and time-intelligence calculations.
* **Data Source:** [`Manufacturing_Analysis.xlsx`](https://github.com/ktaslima060-cloud/Power-BI-Project/blob/main/Manufacturing_Analysis.xlsx)

---

## 📊 Key Features & Analysis
* **Production & Output Tracking:** Monitor overall manufacturing volume, yield rates, and operational efficiency over time.
* **Interactive Filtering:** Drill down by key variables including date ranges, batch runs, line items, and locations.
* **Quality & Downtime Monitoring:** Visualize defect/reject rates, downtime logs, and operational downtime drivers.
* **Visual Insights:** Comprehensive report views backed by dashboard previews included in the `Screenshots/` directory.
